# 🛒 Grocery Sales Analysis – Excel & Power BI

## 📊 Project Overview

This project analyzes grocery sales data using **Excel and Power BI**. The analysis focuses on sales, customers, products, stores, discounts, and purchasing patterns.

## 🎯 Objective

The main objective of this project is to clean and analyze grocery sales data and create an interactive dashboard to identify useful business insights.

## 🛠️ Tools Used

* Microsoft Excel
* Power Query
* Power BI
* DAX

## 🔄 What I Did

* Cleaned and prepared the raw dataset
* Identified and handled missing and inconsistent data
* Created calculated fields and categories
* Analyzed sales and customer-related data
* Created visualizations in Power BI
* Added slicers and filters for interactive analysis
* Built an interactive dashboard

## 📈 Dashboard

The dashboard provides insights into:

* Sales performance
* Customer behavior
* Store performance
* Product and category performance
* Customer loyalty and spending
* Purchase patterns
